# Three.js 开普勒太阳系实现方案

适用于需要在单屏中展示八大行星，同时保留轨道结构真实性的静态网页。

1. 使用 JPL J2000 六轨道根数和世纪变化率计算指定日期的元素。
2. 用牛顿迭代求解偏近点角，将轨道平面坐标变换到 J2000 黄道坐标。
3. 将黄道坐标映射到 Three.js 的 XZ 水平面和 Y 竖直轴。
4. 对半长轴使用单调压缩，只改变轨道间距，不改变偏心率和空间方向。
5. 使用同一模拟日期推进行星，避免分别手填互不一致的动画周期。
6. 使用 OrbitControls 控制旋转和缩放，关闭平移并限制距离与极角。
7. 将 Three.js 入口、core 模块、控件和许可证同时本地托管。
8. 页面显式声明距离与尺寸的可视化比例，避免误导。
