# 技术经验

## Three.js 0.180.0 本地模块需要同时保存 core 文件

`build/three.module.min.js` 会相对导入 `three.core.min.js`。只复制入口文件会在运行时产生 `/vendor/three.core.min.js` 404，且顶层应用代码不会执行。固定依赖时必须一起保存这两个文件，并保留许可证。

## 浏览器 ready 状态与加载遮罩过渡需要分开验证

贴图管理器完成时会立刻设置 ready 数据属性，但加载遮罩还有 500ms 淡出过渡。视觉截图应在 ready 后等待已知过渡完成，再判断最终画面。

## 真实轨道倾角不应人为放大

八大行星多数轨道倾角只有约 0.8°–3.4°，水星约 7°。正确实现从某些视角看起来仍接近同一平面；应通过拖拽观察空间交叉关系，不应为了明显而夸大倾角。
