# icp-web 三维太阳系

这是一个使用 Three.js 构建的单页三维太阳系展示。页面保留本地行星贴图，并依据 JPL 的近似开普勒轨道根数计算八大行星的轨道和运行位置。

## 本地运行

浏览器的 ES Module 与贴图加载需要通过 HTTP 访问，不建议直接双击 `index.html`。

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4173/`。

Three.js 0.180.0、`OrbitControls` 及其 MIT 许可证保存在 `vendor/`。行星与太阳贴图保存在 `textures/`，运行时不依赖第三方 CDN。

## 操作

- 鼠标左键拖拽：环绕太阳系旋转视角。
- 鼠标滚轮：拉近或拉远相机。
- 触摸屏单指拖拽：旋转视角。
- 触摸屏双指缩放：调整相机距离。

相机禁止平移，并设置了最近、最远距离与俯仰边界。

## 科学数据与可视化边界

轨道采用 JPL《Approximate Positions of the Planets》中适用于 1800–2050 年的 J2000 轨道根数和世纪变化率：

- 半长轴 `a`
- 偏心率 `e`
- 轨道倾角 `I`
- 平黄经 `L`
- 近日点黄经 `ϖ`
- 升交点黄经 `Ω`

行星位置由浏览器当前时间开始，通过求解开普勒方程推进。八颗行星使用同一模拟时间倍率，因此保留真实的相对公转周期。

为了在一个屏幕中同时辨认水星至海王星，半长轴使用单调对数压缩；偏心率、轨道方向和倾角不变。太阳与行星半径也采用独立的可视化尺寸。因此，本页面不适合比较天体直径或行星间距离，只适合观察轨道结构、方向和相对运动。

数据来源：<https://ssd.jpl.nasa.gov/planets/approx_pos.html>
