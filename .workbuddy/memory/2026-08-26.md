## ICP 备案展示页（www.evanpatchouli.space）
- 需求：备案过审用的纯静态展示页，无导航、无任何功能入口；高清炫酷动画；太空主题，八大行星绕太阳公转+自转。
- 产出：`index.html`（单文件，无外部依赖）。
  - Canvas 星空（星星闪烁 + 随机流星）作背景层。
  - CSS 3D 倾斜轨道平面（rotateX 68°），JS requestAnimationFrame 驱动八大行星公转（不同半径/周期/初始角），行星本体用 repeating-linear-gradient 条纹 + background-position 动画模拟自转；土星带光环；太阳有脉冲辉光动画。
  - 顶部标题 "EVAN PATCHOULI"（流光文字），副标题"一方星空·静待启程"。
  - 页脚预留备案号占位：`粤ICP备XXXXXXXX号` —— **待用户拿到真实备案号后替换**。
  - 支持 prefers-reduced-motion 与小屏缩放适配。
